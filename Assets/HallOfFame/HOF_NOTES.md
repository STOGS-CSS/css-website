# Filename Notes

In here, the /Assets/HallOfFame/ directory, I'd recommend you give all filenames for people in the Hall of Fame something that reduces ambiguity.

For example, with a name `Firstname Lastname`, use the filename `FirstnameLastname.fileextension`, where the file extension is the correct one for the provided format. Make sure this is a format most browsers can display!

For names that may not be supported by most filesystems, strip them of spaces and anglicise special characters.

For example:
> Joshua Señoron --> `JoshuaSenoron.png`
